# Your games

Every game you are in the middle of, in any game on the site, with the way back into each one.

Nobody is held to one game: you may have two of the same thing going, a tournament besides, and something else in
another game entirely.  None of them needs a tab left open — a game waits as long as its people like, and this page is
how you find it again days later.

A game you have been invited to but nobody has started yet is not here: until it begins there is nothing in it to come
back to, and the invite code is the way to it.  A tournament appears as one line rather than one per table, says which
round it has reached, and tells you when it is waiting on you to be ready or has a game of yours open.

To start something new instead, use **Games**.
